# 🕉️ Bappa Invitation Website

A beautiful and responsive **Ganpati Bappa Invitation Website** created to share the invitation, celebration details, and memories of Ganpati Festival with family and friends.

## 🌺 Features

- 🕉️ Beautiful Ganpati-themed design
- 📱 Fully responsive for mobile and desktop
- 🙏 Ganpati Bappa invitation message
- 📅 Festival date and timing details
- 📸 Previous years' Bappa photos
- 🎵 Festive animations and effects
- 🌸 Traditional Marathi content
- ❤️ Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
